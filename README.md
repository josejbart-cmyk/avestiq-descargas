# AVESTIQ Operativa · descargas

Instaladores de la app de escritorio para Windows. La app se actualiza sola: comprueba al abrir y cada 4 horas.

- Última versión: **0.7.4** → `AVESTIQ-Operativa-Setup-0.7.4.exe`
- Instalación: ejecuta el instalador; crea el icono en el escritorio y en el menú Inicio. Tus datos y tu configuración se conservan al actualizar.
- Windows puede avisar de «editor desconocido» (la app aún no lleva firma de código): pulsa «Más información» → «Ejecutar de todas formas».
